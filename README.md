# Minimalist To-Do

A lightweight, responsive to-do list app built with plain HTML, CSS, and JavaScript. It runs in your browser with no build step or external dependencies.

## Features

- Add, edit, complete, and delete tasks
- Filter tasks by **All**, **Active**, and **Done**
- See remaining task counts and clear completed tasks
- Choose from four color themes: Rose, Ocean, Violet, and Amber
- Automatically save tasks, selected filter, and theme in browser `localStorage`
- Use keyboard shortcuts to work faster
- Responsive layout with reduced-motion support

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.

No installation, server, or build process is required.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Enter` in the task field | Add a task |
| `Escape` in the task field | Clear the field |
| Double-click a task | Edit it |
| `Enter` or `Escape` while editing | Save or cancel the edit |
| `/` | Focus the task field |
| `1` | Show all tasks |
| `2` | Show active tasks |
| `3` | Show completed tasks |

## Data and privacy

Tasks and preferences are stored locally in your browser using `localStorage`. They are not sent to a server. Clearing the browser's site data will remove them.
